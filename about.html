How this gets deployed

No FTP, no server to log into. The repository is the source of truth.

The pipeline

git push → GitHub Actions runs the workflow Azure added to .github/workflows/ → the workflow uploads the files using a deployment token stored as a repo secret → Azure publishes them to its CDN.

Roughly 60–90 seconds end to end. Open a pull request instead of pushing to main and Azure builds a separate preview URL for that branch, which disappears when the PR closes.

Why Static Web Apps

There is no server process here, so there is nothing to keep running, nothing to patch, and nothing to pay for. The free tier covers 100 GB of bandwidth a month, a custom domain, and SSL. When the app eventually needs server-side code, it gets added as serverless functions in the same repository rather than as a separate thing to deploy.
